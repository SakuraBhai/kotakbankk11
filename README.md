# Kotak Mahindra Bank (Kotak 811) Mobile Banking App Clone 🏦

A high-fidelity, interactive, and fully mobile-responsive clone of the **Kotak Mahindra Bank (Kotak 811)** mobile banking application built with modern web technologies (**React 18**, **Tailwind CSS**, **Lucide Icons**, and **Web Audio Synthesis**).

---

## ✨ Key Features & Capabilities

### 1. 🔐 Authentic MPIN Lock Screen & Authentication
- **6-Digit MPIN Keypad**: Interactive numeric keypad with haptic/audio tone synthesis.
- **Biometric FaceID / Fingerprint Simulation**: Quick authentication.
- **Demo 1-Click Fast Login**: Instantly unlocks the banking sandbox for easy demonstration.
- **Safe Simulated Sandbox**: Clearly badged educational prototype with client-side reactive state.

### 2. 💳 Kotak 811 Account Dashboard
- **Live Balance Card**: Real-time balance (₹78,450.50) with show/hide eye toggle for privacy.
- **ActivMoney Auto-Sweep Badge**: Live 7.40% p.a. interest sweep integration with toggle.
- **Account & IFSC Details**: Instant one-click copy buttons for Account Number and IFSC Code.
- **Quick Action Bar**: Fast access to *Send Money*, *Scan & Pay*, *Add Money*, and *Passbook*.

### 3. 💸 Interactive Fund Transfers (UPI & IMPS)
- **UPI & Account Modes**: Transfer via UPI ID, mobile number, or Bank Account + IFSC.
- **Frequent Payees / Beneficiaries**: Instant contact picker.
- **Quick Amount Chips**: Pre-set buttons (+₹500, +₹1,000, +₹2,000, +₹5,000).
- **MPIN Verification & Live Loading**: Secure authorization flow.
- **Instant Digital Receipts**: Detailed breakdown with Reference ID, WhatsApp share simulation, PDF download, and celebratory confetti.

### 4. 📷 Simulated QR Code Scanner (Scan & Pay)
- **Live Viewfinder UI**: Laser line scan animation with dynamic corner brackets and flashlight toggle.
- **One-Tap Merchant Simulations**: Starbucks, Dominos Pizza, DMart Supermarket, and Mumbai Auto Rickshaw.

### 5. 🎴 3D Flippable Virtual Debit & Credit Cards
- **Interactive 3D Card Flip**: Rotate card 180° to reveal CVV and magnetic strip.
- **Security Controls**:
  - Temporary Card Freeze / Lock toggle.
  - Online E-Commerce transactions toggle.
  - International usage toggle.
  - Interactive Daily Spending Limit slider (₹1,000 – ₹1,00,000).
- **Credit Card Tab**: View Kotak League Platinum available credit limit, total limit, and due date.

### 6. 📖 Complete Passbook & Transaction Statement
- **Real-Time Ledger**: Search by payee, merchant, or amount.
- **Filter Tabs**: All, Debits/Spent, Credits/Income, and UPI.
- **e-Statement Download**: Simulated PDF statement export.
- **Transaction Receipt Modal**: View detailed ledger entry for any transaction.

### 7. ⚡ Bharat BillPay (BBPS) & Recharge Hub
- **Categories**: Electricity, Mobile Recharge, FASTag, DTH, Broadband, Piped Gas, Water, and Credit Card Bills.
- **Instant Bill Fetch & Settlement**: Interactive mock bill payments with balance deduction.

### 8. 📈 Kotak ActivMoney & FD Return Calculator
- **Interactive FD Calculator**: Real-time interest calculation with deposit amount slider and tenure pills (390 Days at 7.40% p.a., 1 Year, 2 Years, 5 Years).
- **Mutual Funds SIP Explorer**: Zero-commission direct mutual funds with return tracking.

### 9. 📱 Mobile View Simulator & Responsive Switcher
- **iPhone 16 Mockup Frame**: Dynamic Island, status bar with live clock, signal, Wi-Fi, and battery indicator.
- **Full-Screen Responsive View**: Fluidly adapts across tablets, phones, and desktop screens.

---

## 🚀 How to Run Locally

```bash
# 1. Install dependencies (already installed)
npm install

# 2. Start the Vite local development server
npm run dev
```

Open your browser at `http://localhost:3000` to interact with the Kotak 811 banking clone!
